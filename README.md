A full-stack web application to manage personal finances by tracking income and expenses in one place. The application helps users organize transactions, monitor spending, and understand their financial habits.

✨ Features
🔐 User Authentication – Secure registration and login.
💵 Income Management – Add, edit, delete, and track income transactions.
💸 Expense Management – Record and manage daily expenses.
📊 Financial Overview – View income, expenses, and balance summaries.
📅 Time-Based Filtering – Filter transactions by day, week, month, or year.
📥 Excel Export – Download transaction data for record keeping.
👤 User Profile – Manage user-related information.
📱 Responsive Interface – Use the application on different screen sizes.
